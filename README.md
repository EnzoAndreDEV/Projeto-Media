# Calculadora de Média

Projeto desenvolvido em C++ como parte dos meus estudos de lógica de programação.

## Sobre o projeto

O programa realiza o cálculo da média aritmética de duas notas informadas pelo usuário. Após receber os valores, executa a operação matemática e apresenta o resultado no terminal.

## Funcionalidades

- Entrada de duas notas.
- Cálculo automático da média.
- Exibição do resultado no terminal.

## Tecnologias utilizadas

- C++
- `stdio.h`
- `printf` e `scanf`


## Objetivo

Praticar conceitos fundamentais de programação, como declaração de variáveis, entrada e saída de dados e operações matemáticas.
